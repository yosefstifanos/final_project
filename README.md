**Author:** Yosef Stifanos

**Dataset:** [Video Games Dataset (Portsmouth Research Portal)](https://researchportal.port.ac.uk/en/datasets/video-games-dataset)

## 📌 Overview

This project applies both linear and logistic regression techniques to a dataset of over 1,000 video games released between 2004 and 2010. Our goal was to uncover relationships between game features (such as review scores, year released, and platform) and their sales, as well as to build a classification model based on gameplay type.

## 💡 Objectives

1. **Linear Regression** – Predict U.S. sales (in millions) based on game attributes.
2. **Logistic Regression** – Classify whether a game is Third Person based on its features.
3. Evaluate model performance using metrics such as R², RMSE, AUC, and classification accuracy.
4. Visualize regression assumptions through residual and Q-Q plots.

## 🛠️ Tools & Libraries

- Python (Jupyter Notebook)
- `pandas`, `numpy` for data wrangling
- `matplotlib`, `seaborn` for visualization
- `sklearn` for model building and evaluation
- `statsmodels` for regression diagnostics

## 📈 Key Takeaways

- Linear regression revealed that review scores and number of players had the strongest correlation with U.S. sales.
- Logistic regression identified that certain platforms and camera perspectives were predictive of Third Person gameplay.
- The classifier achieved strong accuracy and AUC scores, making it suitable for categorization tasks in future analyses.
